# FOR-009 — Cloud Evidence-Source Boundary

Cloud evidence is a separate future source family. WP-0450 may describe
collection possibilities but must not acquire cloud data.

Distinct source families include Apple local computer backup, iCloud device
backup, iCloud Photos, Messages in iCloud, iCloud Drive, synchronized Notes,
Contacts, Calendar, and other separately synchronized services. An iCloud
device backup is not a complete acquisition of an iCloud account.

Future WP-1900 requires separate owner approval and documented lawful
authorization, authentication and credential/token protection, Advanced Data
Protection implications, provenance, integrity verification, rate limiting,
compatibility profiles, lawful test datasets, production capacity, and support
promotion. No cloud acquisition is currently implemented or supported.
