# Fixture Claims Boundary

| Observation | Permitted | Prohibited |
|---|---|---|
| SHA-256 match | Bytes consistent between named observations | Apple authenticity, nonrepudiation, support |
| Expected event found | Candidate behavior on exact fixture/profile | Universal compatibility or parser support |
| Expected event not found | Factual non-observation under recorded run | Deletion, device absence, concealment, incompleteness |
| One successful fixture | Exact device/software/OS/schema/profile result | Broader compatibility envelope or production readiness |

Future support requires a defined envelope, adequate positive/negative and
multi-fixture validation, parser-specific validation, independent review, and
explicit owner promotion.
