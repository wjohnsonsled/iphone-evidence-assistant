# Fixture Minimization Checklist

- [ ] Dedicated controlled test accounts where possible
- [ ] Unrelated accounts and personal content removed before acquisition
- [ ] No client, litigation, employee, family, confidential business, or third-party data
- [ ] No real authentication secrets in records
- [ ] Unnecessary photo, email, health, financial, location, and cloud content excluded
- [ ] Only minimum test artifacts created
- [ ] Pre-backup and pre-transfer reviews recorded
- [ ] Restricted encrypted-at-rest storage and named access control confirmed
- [ ] Completed backup will not be altered for minimization
